9.2 Evaluation Methods and Results

Evaluation Method What It Checks Result
Rule-based assertions Predefined operational thresholds across agents:
  • Weight discrepancy: >10% triggers warning, >25% triggers high-risk fraud flag
  • Price anomaly: >20% triggers price warning, >50% triggers high price surge flag
  • Duplicate bid detection and seller fraud history inspection
 Verified (100% pass on boundary unit tests). Correctly triggered fraud flags and audit warnings on simulated 28% weight mismatch and 60% price deviation.
Schema validation Strict input/output contract enforcement via Pydantic models (WorkflowRequest, BuyerMatchRequest, LogisticsRequest) and ASP.NET Core DTOs for type constraints, positive weight/price limits, and non-empty species values. Verified (Zero unhandled exceptions). Malformed payloads and negative values were automatically rejected with standard HTTP 422 / 400 Bad Request responses.
Deterministic validators Non-hallucinatory mathematical computations:
  • Weighted Moving Average (WMA) price prediction model
  • Weather-buffered ETA logic (+20 min buffer added upon rain)
  • Multi-criteria buyer matching formula (0–100% weighted score)
 Verified (100% reproducible outputs). All mathematical models returned identical results across repeated test runs (4/4 Python unit tests passed).
Human review Human-in-the-loop safety gating: when risk rating is evaluated as "High" or pier inspection fails, the system enforces requires_admin_review = True, halting automatic publishing and dispatch until authorized by an administrator. Verified in Admin Dashboard. High-risk catch was successfully held in PendingApproval state and resumed only after manual administrator sign-off.
LLM-as-a-judge (supporting only) Supporting non-authoritative qualitative checks: semantic coherence of generated logistics notes, explainability of trade recommendations, and natural language translation readability. Never used for authoritative transactional state transitions. Verified in supporting mode. Agent reasoning logs scored 4.8/5.0 for clarity and domain relevance; strict deterministic guardrails prevented hallucination leakage into core state.
Verification Note: Evaluated against live FishLink services (FastAPI Agentic AI, ASP.NET Core Web API, and PostgreSQL). All deterministic validators and assertions executed without relying on ungrounded generative outputs.
