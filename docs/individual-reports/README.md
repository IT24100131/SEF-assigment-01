# Individual report instructions

Create one file per student, for example `student-01.md`. The student must
write the contribution and reflection in their own words.

## Required sections

1. Student name and registration number.
2. Primary component and why it is technically distinct.
3. Backend/API, database, React, Flutter and Agentic AI contributions.
4. Commit, issue and pull-request links proving ownership.
5. Tests written, test output and one failure/debugging example.
6. Architecture/security/state-management decisions understood by the student.
7. AI usage log link.
8. Individual reflection: what was changed, rejected, verified and learned.
9. Viva change proposal and the expected implementation steps.
